# THUBO I24 새 STL

PLA용 새 출력물 11종, 총 13개다. L34_common_frame과 R34_common_frame은 각각 **2개**, 나머지 9종은 각각 1개다. 기존 L6/R6 발바닥은 그대로 사용한다.

FIT_FIRST의 F7은 먼저 모터 후면을 맞춰 볼 시험편이다. F8은 Orange Pi 5 RK3588S 원형 모델의 보드 구멍 확인용이다. 두 시험편은 로봇 구성품이 아니다.

STL은 출력 방향과 바닥 정렬이 반영되어 있다. A1/0.4mm/PLA/층0.2mm/6벽/45% gyroid로 슬라이싱했다. 다리와 P0는 자동 지지재, B1/N1과 시험편은 지지재 없이 준비했다. 보드 스탠드오프는 M2.5 암–암 12mm 4개다.

모터 케이스 후면 판6mm와 구멍Ø2.5/피치20.5×24.45를 제공 STEP에서 반영했다. M2×8+0.5mm 와셔는 후보 길이이며 실제 나사/깊이를 F7에서 확인한다. 제공 파일 내부 모터명은 ST-3235M으로 파일명 ST-3250M과 다르다. 실제 모터 동일성, 체결 및 PLA 내구성은 미검증이다. 후면 창과 나사 구멍 사이의 최소 명목 살은 약1.52mm다.

자세한 조립 STEP·한국어 안내·기존 발바닥·검사 결과는 전체 THUBO_I24_Symmetric_Legs_Pelvis.zip에 있다. 표본 CAD 간섭 검사 통과는 실제 보행/연속 전 범위 동작/피로 검증을 의미하지 않는다.
