# THUBO I24 A1 출력 프로젝트

Bambu Lab A1 / PLA / 노즐0.4 / 층0.2 / 벽6줄 / 45% gyroid.

로봇 본품은 11개 3MF 프로젝트, 총13개 출력물이다. **L34와 R34의 각 3MF에는 이미 두 개가 들어 있다.** 각각 한 판만 출력한다. 다른 본품은 한 개씩이다. 기존 발바닥은 재사용하므로 이 프로젝트 묶음에 없다.

F7/F8은 선택 맞춤 시험편이다. F7을 먼저 출력해 실제 모터 후면 구멍·돌기·커넥터·나사 길이를 확인한다. F8은 원형 Orange Pi 5 보드 구멍 확인용이다.

배치/방향을 유지하고 프린터와 실제 PLA를 확인한다. 다리와 골반P0는 자동 지지재를 포함했다. 트레이B1/전면판N1/시험편은 지지재가 없다. 모든 프로젝트를 슬라이싱하고 압축 무결성·베드 범위·수량을 확인했다. 프린터로 전송하거나 실제 출력한 것은 아니다.

본품 11판 슬라이서 추정 합계 1162.79g / 76시간3분(지지재 포함). 시험편과 기존 발은 제외했다. 나사 길이·PLA 실제 강도/피로·완성 배선·냉각·실제 보행은 아직 미검증이다. 자세한 안내는 전체 패키지를 참고한다.
