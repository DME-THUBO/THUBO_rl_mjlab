# THUBO 平移速度命令：正运动学与跨步位移核算

## 结论先行

按 MJCF 连杆偏移和关节位置范围做腿部正运动学核算，当前平移命令**几何上可行**。为把速度换算为每次左右脚交替落地的位移，本文采用明确的参考假设：完整步态周期 `T=0.50 s`（每秒 2 个完整周期，每 `T/2=0.25 s` 交替一次支撑脚）。于是：

- `vx=+0.4 m/s`：每次交替落脚需要前进 `0.4 * 0.25 = 0.100 m`；`vx=-0.4 m/s` 时后退 `0.100 m`。腿部固定站立高度的简化 FK 前后可达约 `-0.111..+0.107 m`，因此每一步需要的水平足端位移刚好在几何极限内，但余量很小，且极限位姿没有抬脚、动力学和稳定性余量。任务当前只采样 `vx=0..0.4`，不含后退。
- `vy=+0.1 m/s`：每次交替落脚需要向左（正 y）`0.1 * 0.25 = 0.025 m`；`vy=-0.1 m/s` 时向右 `0.025 m`。该位移小于足底横向半宽 `0.044 m`，且髋/踝 roll 关节范围为 `+-0.65 rad`，侧移需求在几何尺度上较小。
- 判断：`vx=0..0.4 m/s` 与 `vy=+-0.1 m/s` 对正运动学来说可行，可作为保守到中等的初始范围。实际稳定速度仍会受摆腿抬高、关节力矩/速度、接触摩擦、步态策略和 PPO 是否学到有效步态限制；FK 不能证明策略能跟踪。

跨步结果与周期成正比。若实际完整步态周期不是 `0.50 s`，按 `d_step = v * T / 2` 线性替换即可。此处不从 MJCF 臆造步态周期；`0.50 s` 是用于检查当前速度量级的显式基准假设。

## 1. MJCF 几何与正运动学模型

模型文件为 [`mjcf/THUBO.xml`](../mjcf/THUBO.xml)。左右腿结构相同，骨盆根高为 `0.39 m`。从 pelvis 到髋 pitch 关节原点的竖直偏移为 `+0.043 - 0.043 - 0.075 = -0.075 m`，所以髋 pitch 原点约在 `z=0.315 m`。从该关节到足底 site 的近似串联长度为：

```text
髋 pitch -> 膝       0.100 m
膝 -> 踝 pitch      0.100 m
踝 pitch -> 踝 roll  0.075 m
踝 roll -> sole     0.059 m
合计                0.334 m
```

对前后方向，令髋 pitch、膝、踝 pitch 角依次为 `q_h, q_k, q_a`，足底 site 近似正运动学为：

```text
theta = [q_h, q_h + q_k, q_h + q_k + q_a, q_h + q_k + q_a]
x = sum(L_i * sin(theta_i))
z = -sum(L_i * cos(theta_i))
L = [0.100, 0.100, 0.075, 0.059] m
```

令足底落地 `z=-0.315 m`（相对髋 pitch 原点），并满足 XML 关节范围 `q_h=-1.4..1.05 rad`、`q_k=0..2.1 rad`、`q_a=-1.2..1.2 rad`，带等式约束 `z=-0.315 m` 的数值优化得到固定根高下约 `x=-0.111..+0.107 m`。极限附近膝接近伸直；这只是平面静态几何范围，不包含足底姿态限制、碰撞、摆动离地高度或执行器能力。

足底碰撞盒半尺寸为前后 `0.080 m`、左右 `0.044 m`。因此计算落脚点时，足底覆盖区能提供额外接触边缘，但本文不把足底长度加进 `0.115 m` 的足底 site 关节工作空间，以避免重复计算支撑范围。

## 2. 当前 vx 范围的逐项跨步计算

交替步长定义为 `d_x = vx * T / 2`，`T/2=0.25 s`：

| 机体命令 `vx` | 0.25 秒内机体前后位移 | 每次交替落脚需要的足端位移 | 与 FK `+-0.115 m` 比较 |
| ---: | ---: | ---: | --- |
| `-0.4 m/s` | `-0.4 * 0.25 = -0.100 m` | 后方 `0.100 m` | 几何可达，约剩 `0.011 m` 静态余量 |
| `-0.2 m/s` | `-0.2 * 0.25 = -0.050 m` | 后方 `0.050 m` | 几何可达 |
| `0.0 m/s` | `0.0 * 0.25 = 0.000 m` | `0.000 m` | 原地站立/踏步 |
| `+0.2 m/s` | `+0.2 * 0.25 = +0.050 m` | 前方 `0.050 m` | 几何可达 |
| `+0.4 m/s` | `+0.4 * 0.25 = +0.100 m` | 前方 `0.100 m` | 几何可达，约剩 `0.007 m` 静态余量 |

配置实际范围为 `vx=0..0.4 m/s`，因此实际只用上表后 3 档。`0.4 m/s` 在 `T=0.5 s` 时需要前向工作空间的约 `0.100/0.107=93%`，后向若作对称参考则需 `0.100/0.111=90%`；这意味着数学上可达但动态余量偏小。如果学到的周期更短，例如 `T=0.4 s`，则单次交替步长降为 `0.080 m`，占前向工作空间约 75%；如果周期更长，所需步长也更大。

## 3. 当前 vy 范围的逐项跨步计算

对侧向命令，交替步长定义为 `d_y = vy * T / 2`。正 y 按 MuJoCo 坐标约定为左侧：

| 机体命令 `vy` | 0.25 秒内机体侧向位移 | 每次交替落脚的侧向位移 | 尺度判断 |
| ---: | ---: | ---: | --- |
| `-0.10 m/s` | `-0.10 * 0.25 = -0.025 m` | 向右 `0.025 m` | 小于足底横向半宽 `0.044 m` |
| `-0.05 m/s` | `-0.05 * 0.25 = -0.0125 m` | 向右 `0.0125 m` | 明显小于足底横向半宽 |
| `0.00 m/s` | `0.00 m` | `0.000 m` | 无侧向步长 |
| `+0.05 m/s` | `+0.05 * 0.25 = +0.0125 m` | 向左 `0.0125 m` | 明显小于足底横向半宽 |
| `+0.10 m/s` | `+0.10 * 0.25 = +0.025 m` | 向左 `0.025 m` | 小于足底横向半宽 `0.044 m` |

当前任务配置覆盖 `vy=-0.1..+0.1 m/s`，两侧方向所需跨步完全对称。从几何量级看，该侧向范围可行且保守。由于腿的髋间距约 `0.11 m`，`0.025 m` 侧移不是零扰动，但远小于腿长；仍需用 roll 关节、足底接触和躯干平衡共同实现。

## 4. 可行性边界与未由 FK 证明的内容

- `src/tasks/velocity/config.py` 设定 `vx=0..0.4 m/s`、`vy=-0.1..0.1 m/s`，上面的跨步演算针对的是**机体每次左右交替支撑期间的位移需求**，不是每只脚在完整周期中的总摆动行程。完整周期内同一只脚从后向前的行程约为 `vx*T`，交替落脚间距为其一半。
- 当前参考步态周期 `0.50 s` 不是 XML 参数；通过 FK 可以验证足端位置是否可达，但不能从 MJCF 单独推出实际步频或稳定速度上限。
- XML standalone motor 限矩为 `1.4 N m`，但当前 MJLab 通过 [`dme_thubo/robot.py`](../dme_thubo/robot.py) 删除 XML motors 并使用 `effort_limit=8.716 N m` 的位置执行器；执行器速度 metadata 为 `8.938 rad/s`。这些影响动态跟踪能力，但不改变上面的关节位置正运动学工作空间。
- `wz` 不是足端平移步长，不能用以上平移 FK 表格验证。当前 `wz=-0.6..+0.6 rad/s` 的可行性需要转向步态仿真或基于支撑脚间距、步频做单独核算。

因此，仅从正运动学上限判断：当前 `vy` 范围有明显几何余量；`vx=0.4 m/s` 在 `0.5 s` 周期假设下仍在足端几何范围内，但仅剩约 `7 mm` 前向静态余量，结论为“几何可达、动态余量存疑”，建议仿真时重点验证该最高档。不能据此宣称已达到稳定可跟踪速度。
